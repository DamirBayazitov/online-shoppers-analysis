# Online Shoppers Purchasing Intention


## Задачи и данные

Цель - предсказать, закончится ли посещение интернет-магазина покупкой. Целевая переменная - Revenue.

Используется Online Shoppers Purchasing Intention Dataset.

Я выбрал этот датасет, потому что задача понятна с практической точки зрения и позволяет сравнить разные методы классификации.

Источник: 
https://www.kaggle.com/datasets/imakash3011/online-shoppers-purchasing-intention-dataset

Файл данных: data/online_shoppers_intention.csv


## Список гипотез до начала экспериментов:

1. Random Forest превзойдёт логистическую регрессию по F1
   класса «покупка».
2. Масштабирование числовых признаков повысит F1
   логистической регрессии.
3. class_weight='balanced' повысит recall класса «покупка»
   у логистической регрессии относительно модели без весов.
4. У дерева без ограничения глубины разрыв между обучающим
   и проверочным F1 будет больше, чем у дерева с max_depth=5.
5. Отбор половины признаков после кодирования через
   SelectKBest с f_classif снизит F1 логистической регрессии
   не более чем на 0.02.
6. Подбор порога классификации для логистической регрессии
   даст больший F1, чем стандартный порог 0.5.


## План экспериментов

- Выделить 20% данных в тестовую выборку с сохранением долей
  классов и random_state=42.
- Проводить EDA и выбирать настройки на обучающей выборке.
- Использовать стратифицированную кросс-валидацию на 5 фолдах.
- Обучать обработку пропусков, кодирование, масштабирование
  и отбор признаков внутри Pipeline на обучающих фолдах.
- Сравнить DummyClassifier, Logistic Regression,
  Decision Tree и Random Forest.
- Подбирать параметры и порог без использования тестовой выборки.
- Основная метрика — F1 класса «покупка».
  Дополнительно: precision, recall, accuracy и ROC-AUC.
- Гипотезы сравнивать по результатам кросс-валидации.
  Тестовую выборку использовать для итоговой оценки.
